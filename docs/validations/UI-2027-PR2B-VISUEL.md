# Provenance du paysage PR2b

Création du 16 novembre 2026 avec l’outil intégré **OpenAI ImageGen**,
à la demande du propriétaire pour le hero Mon BPREA. Aucun téléchargement
de photographie tierce, aucune image fournie au générateur ; la maquette a guidé
la composition au moyen du texte ci-dessous. Paysage synthétique décoratif,
pas une photographie documentaire d’une exploitation réelle.

Le résultat original `exec-2fd8de4d-cae8-421b-8289-a81de0f5c1c7.png`
est conservé dans le dossier privé de génération Codex. Les fichiers livrés sont
`assets/revision-landscape-1600.webp` (1600 × 533, 102 764 octets) et
`assets/revision-landscape-960.webp` (960 × 320, 37 084 octets).
Encodage WebP qualité 0,78 par Canvas dans le Chromium verrouillé du projet.
Seule une variante est chargée par visite grâce à `srcset` ; aucun service
d’images extérieur n’est appelé. La petite variante utilise un cadrage CSS
privilégiant la serre sur mobile. Dimensions réservées, chargement prioritaire
et préchargement responsive, aucun chargement différé du hero.

Les [conditions européennes OpenAI, section Content](https://openai.com/policies/eu-terms-of-use/)
consultées le 16 novembre 2026 attribuent à l’utilisateur les droits d’OpenAI
sur les sorties, dans la mesure autorisée par le droit applicable. Elles
précisent aussi que des sorties peuvent être similaires : aucune exclusivité
ou garantie de protection par droit d’auteur n’est revendiquée ici.
L’asset est fourni pour utilisation et distribution dans Mon BPREA.
